# Ledger Review concept

A reviewer should be able to upload invoices and ledgers, see extraction progress, compare structured results to the original document, and correct discrepancies with an audit trail.

The first working slice is batch upload through an independent document worker to a reviewable invoice. It must support digital and scanned PDFs, common image formats, Excel and CSV. Missing values are preserved, and validation flags discrepancies for a human reviewer. Search and PDF-to-PDF or PDF-to-Excel reconciliation should use the same stored results.

Development stages were assembled for submission from the archived baseline and the current worktree. Commit dates reflect when the submission history was assembled.
